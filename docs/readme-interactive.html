CodeTracker

简介

本地离线「代码活动记录」桌面应用（MVP）：SQLite 存数据，Vue + Electron 做界面，Express 提供本地 API。数据不出本机，无需登录。

MVP 功能

模块 说明
仪表盘 汇总、迷你热力图（当前 UTC 年）、快速记日志、最近动态
日志 筛选 / 分页 / 增删改；可新建项目
热力图 GitHub 风格；仅 2026 年起 UTC 自然年
统计 全局汇总、7/30 日卡片
设置 语言、API 基址、健康检查、仓库链接

REST 契约见 backend/docs/api.md。

开发运行

  1. 根目录 npm install；cd backend && npm install
  2. 终端 A：cd backend && npm start（默认 127.0.0.1:3033，库 database.db）
  3. 终端 B：根目录 npm run dev

可选环境变量 VITE_API_BASE 覆盖 API 根地址。

生产构建

  • npm run build — 仅编译
  • npm run dist — 安装包 + portable（内置后端）
  • npm run dist:dir — 仅解包 win-unpacked

安装版数据库：%AppData%\Roaming\codetracker\codetracker.db（与开发用 backend/database.db 不同）。

Overview

A local-first desktop app for logging coding activity (MVP): SQLite storage, Vue + Electron UI, Express HTTP API on your machine. No cloud account; data stays offline.

MVP features

Module Notes
Dashboard Summary, mini heatmap (UTC calendar year), quick log, recent feed
Logs Filter / paginate / CRUD; create projects in-app
Heatmap GitHub-style grid; years ≥ 2026 (UTC)
Statistics Global totals, 7/30-day cards
Settings Locale, API base, health ping, repo link

REST contract: backend/docs/api.md.

Develop

  1. Root: npm install; cd backend && npm install
  2. Terminal A: cd backend && npm start (default 127.0.0.1:3033, DB database.db)
  3. Terminal B: root npm run dev

Optional: VITE_API_BASE to override the API origin.

Ship

  • npm run build — compile only
  • npm run dist — NSIS + portable (embedded backend)
  • npm run dist:dir — unpacked win-unpacked

Packaged DB path: %AppData%\Roaming\codetracker\codetracker.db (separate from dev backend/database.db).
